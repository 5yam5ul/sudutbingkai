# Sudut Bingkai 📸

Kamera Sekali Pakai Digital Berbasis Web untuk Pernikahan & Event Spesial.

## Fitur Utama
- **Zero App Download**: Cukup scan QR code lewat kamera HP, tanpa instal aplikasi.
- **8 Film Preset Autentik**: Kodak Portra 400, Fuji Superia, CineStill 800T, Ilford HP5, Agfa Vista, Tri-X 400, dll.
- **Dual-Mode Backend**: Didukung Supabase PostgreSQL & Cloud Storage dengan performa tinggi.
- **Live Gallery & Slide Proyektor**: Foto tamu tampil otomatis di layar resepsi secara real-time.
- **Pesan Suara Digital**: Tamu bisa meninggalkan ucapan audio vintage langsung dari kamera.

---
Built with Next.js 15, Tailwind CSS, TypeScript, and Supabase.
